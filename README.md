
Dungeon Legends

My first Unity project — a small top-down dungeon crawler. Still learning game dev, so it's rough around the edges but I had fun building it 🎮

About

A 2D top-down dungeon crawler built in Unity. The player navigates a room, avoids a chasing enemy, collects a key, and escapes through a locked door before health runs out.

Features
Player movement using Rigidbody2D physics
Enemy AI with vector-based chase logic
Health/damage system using trigger collisions
Key pickup and inventory-gated win condition
Game Over and Win state UI
Tech
Unity 6 (2D URP)
C#
How to run
Clone the repo, open the project in Unity, open the scene in Assets/Scenes, hit Play
Or run the built .exe from the Build folder (Windows)
Controls
WASD / Arrow keys — move
Avoid the enemy, grab the key, reach the door to win
